# Roadmap

- [x] **Fase 0 — Fundação**: setup do projeto, estrutura multi-tenant, autenticação, painel administrativo básico.
- [ ] **Fase 1 — Núcleo comercial**: clientes, produtos, estoque, fornecedores.
- [ ] **Fase 2 — Vendas e financeiro**: PDV, contas a pagar/receber, fluxo de caixa.
- [ ] **Fase 3 — E-commerce**: catálogo, carrinho, checkout, painel do cliente final.
- [ ] **Fase 4 — Fiscal e logística**: NF-e/NFC-e, frete, rastreamento.
- [ ] **Fase 5 — WhatsApp e automação**: inbox, chatbot, automações de mensagens.
- [ ] **Fase 6 — Relatórios e BI**: dashboards, indicadores.
- [ ] **Fase 7 — Preparação para SaaS**: planos, cobrança recorrente, onboarding self-service, super-admin.
